## Repository Structure

- `docs/notes/` — Lecture notes and topic mapping
- `docs/discussions/` — Own discussion attempts and notes
- `docs/homework/` — Own homework solutions and reflections
- `docs/exams/` — Exam notes and personal attempts
- `docs/reports/` — ASIC experiment results and PPA analysis
- `rtl/` — Independent RTL and testbenches
- `labs/` — Adapted Spring 2026 ASIC Labs
- `projects/` — Spring 2026 ASIC project and independent hardware designs
- `scripts/` — Simulation, synthesis and physical design automation

## Tools and Scope

Target technology: **SKY130**. Tools for independent implementation may include Verilator, Yosys, OpenROAD and other open-source EDA utilities. Public skeleton code does **not** imply that Berkeley's commercial EDA licenses, private configuration, or graded services are available.
